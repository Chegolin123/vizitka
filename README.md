# Сайт-визитка

Персональный сайт-визитка для web full-stack разработчика.
Построен на **Next.js 14 (App Router) + TypeScript + Tailwind CSS**.

## Возможности

- 🎨 Креативный тёмный дизайн с градиентами и анимациями
- ✨ Появление элементов при скролле (IntersectionObserver)
- 📱 Полностью адаптивный, с мобильным меню
- ♿ Уважает `prefers-reduced-motion`
- 🔍 SEO: метаданные и OpenGraph
- ⚡ Секции: Hero, О себе, Навыки, Контакты
  (портфолио — следующий шаг)

## Быстрый старт

```bash
npm install      # установить зависимости
npm run dev      # запустить дев-сервер → http://localhost:3000
npm run build    # продакшн-сборка
npm run start    # запустить продакшн-сборку
npm run lint     # проверить линтером
```

## Кастомизация

Почти весь контент вынесен в один файл — **`lib/content.ts`**.

Там меняешь:

| Поле           | Что это                                      |
| -------------- | -------------------------------------------- |
| `profile`      | Имя, роль, локация, email, тэглайн, статус   |
| `about`        | Параграфы «о себе» и метрики-счётчики        |
| `skills`       | Группы навыков с иконками-эмодзи             |
| `socials`      | Ссылки на соцсети (иконки подставятся сами)  |
| `nav`          | Пункты меню                                  |

Акцентный цвет и тема настраиваются в `tailwind.config.ts` (`colors.accent`).

## Структура

```
.
├── app/
│   ├── globals.css      # Tailwind + глобальные стили и утилиты
│   ├── layout.tsx       # Корневой layout, шрифты, metadata
│   └── page.tsx         # Главная страница — собирает секции
├── components/
│   ├── ui/
│   │   ├── Background.tsx  # Декоративный фон (свечения, сетка)
│   │   ├── Navbar.tsx      # Sticky-навбар + мобильное меню
│   │   ├── Reveal.tsx      # Анимация появления при скролле
│   │   └── Icons.tsx       # SVG-иконки соцсетей
│   └── sections/
│       ├── Hero.tsx
│       ├── About.tsx
│       ├── Skills.tsx
│       ├── Contact.tsx
│       └── Footer.tsx
├── lib/
│   └── content.ts       # ← ВЕСЬ ТЕКСТОВЫЙ КОНТЕНТ ЗДЕСЬ
├── tailwind.config.ts
├── tsconfig.json
└── next.config.mjs
```
