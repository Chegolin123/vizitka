# План: Dev-фича — ручная настройка focal point фото на карточках портфолио

## Концепция
В dev-режиме (`process.env.NODE_ENV !== "production"`) на каждой карточке карусели появляется **draggable focal-point маркер**. Двигая его, меняешь `object-position` изображения карточки (X/Y в %). Настройки сохраняются в `localStorage`, переживают перезагрузку (только в dev). Внизу показывается готовая строка для копирования в `content.ts`.

## Архитектура

### 1. Тип данных — `lib/content.ts`
Расширить `Story` опциональным полем:
```ts
// Focal point для object-position, например "30% 20%".
// Настраивается через dev-drag (см. ImageFocusEditor). В production не влияет если undefined.
imageFocus?: string;
```
+ применить в Carousel: `style={{ objectPosition: effectiveFocus }}`.

### 2. Новый компонент `components/ui/ImageFocusEditor.tsx` (~140 строк)
dev-only overlay, рендерится поверх image-зоны карточки:
- **Маркер**: круг 24px, clay-цвет, `position: absolute`, `left/top` = focus X/Y
- **Drag**: onPointerDown → захват pointer (setPointerCapture), onPointerMove → пересчёт % относительно границ контейнера, clamp 0–100
- **State**: `focusX`, `focusY` (useMotionValue или обычный useState)
- **localStorage**: ключ `vizitka:imgfocus:<storyId>`, читается при mount, пишется при изменении (debounced 300ms)
- **Кнопка "копировать"**: копирует в clipboard строку `imageFocus: "X% Y%",` для вставки в content.ts
- **Кнопка "сбросить"**: удаляет localStorage-запись, возвращает object-center
- **Hidden в production**: `if (process.env.NODE_ENV === "production") return null;`
- **Hidden при reduced-motion**: нет, drag нужен всегда в dev
- **z-index высокий** (`z-[100]`), `pointerEvents: auto`, НЕ вмешивается в carousel-drag (drag стартует только по маркеру, не по всему контейнеру)

### 3. Интеграция в `components/ui/Carousel.tsx`
Внутри `CarouselCard` (где рендерится `<Image>`):
- Прочитать focus из localStorage при mount (`useState` initializer)
- Применить к Image: `className="object-cover"` + `style={{ objectPosition: focus }}` (если focus есть, иначе `object-center` как сейчас)
- Отрендерить `<ImageFocusEditor>` поверх image-зоны (dev-only, рендерится всегда но компонент сам возвращает null в prod)
- **Изолировать drag-события**: ImageFocusEditor использует `stopPropagation` в onPointerDown чтобы carousel-drag не срабатывал при настройке фото

### 4. Dev-badge в углу
В `app/layout.tsx` или отдельный `<DevBadge>` — маленькая плашка в углу экрана "🔧 DEV: focus-edit mode" (только в dev), чтобы было понятно что включен dev-режим.

## Механика работы (пользовательский поток)

1. Дева открывает `localhost:3000`, идёт в карусель
2. На каждой карточке видит clay-маркер (круг) поверх фото
3. Двигает маркер → фото мгновенно меняет focal point (object-position)
4. Находит идеальную позицию (например, чтобы UI кейса был виден)
5. Жмёт "📋" под карточкой → в clipboard строка `imageFocus: "42% 15%",`
6. Вставляет в `content.ts` для соответствующего `id` кейса
7. Настройки сохранены в localStorage → при следующем заходе в dev видит свои позиции
8. При `npm run build` (production) — маркеров нет, берётся `imageFocus` из content.ts (или object-center если не задан)
